# Logos couleur — sources et statut

Tous les logos sont des marques déposées de leurs titulaires. Les mentions « domaine public » de Wikimedia portent sur le droit d'auteur (logo typographique simple), pas sur le droit des marques.
Contrôles faits sur chaque fichier : type réel (pas de page HTML), présence de couleur, transparence autour du logo, rendu identique sous resvg et Chromium.
